# XSIME legacy documentation routes

Public static compatibility site for 犀术IME / 犀術IME / XSIME.

`/rimes/ios/`, `/rimes/ios/support/` and `/rimes/ios/privacy/` preserve the historical GitHub Pages paths when the source repository moves to `scholay/xsime`. This repository must remain named `scholay.github.io`; do not recreate a `scholay/rimes` repository after the source rename, because that would override GitHub repository redirects.

The source project was renamed to `scholay/xsime` on 2026-10-15. These compatibility files preserve the source project's `docs/ios` pages at their original paths. Update the copies when support or privacy content changes. Public routes must be checked separately from deployment status; the old privacy route returned HTTP 200 after cutover.

No analytics, credentials, filing documents or user data are included.
